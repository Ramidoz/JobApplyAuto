Workflow
1
Score and Filter Jobs
Claude scores each new listing on skills match, seniority fit, STEM OPT sponsor likelihood, and role type. Only jobs above the threshold in target_criteria.md proceed. Low-scorers are logged as "skipped" with reason.
Safe to automate
2
Tailor Resume per Job
Pulls from master_resume.md and rewrites bullet points to match the JD's keywords, stack, and level. Outputs a single-page .docx saved to Google Drive as Rohit_Ananthan_[Company]_Resume.docx.
Safe to automate
3
Generate Cover Letter
Drafts a tailored cover letter using your tone preferences, JD context, and a company brief fetched via web search. Saved alongside the resume in Drive.
Safe to automate
4
Submit Application via Claude in Chrome
For LinkedIn Easy Apply and Wellfound: Claude in Chrome fills and submits the form. For Greenhouse/Lever: attaches files and submits. For Indeed: uses Quick Apply. Automatically skips any form requiring SSN, manual password, or payment.
Automated submission
5
Draft LinkedIn Outreach Message
Generates a personalized connection request or cold message to a DS hiring manager or team lead at the company. Saved as a draft in Drive for you to send manually.
Draft only, not auto-sent
6
Log and Set Follow-up
Appends a structured row to applications_tracker.json with company, role, date, match score, resume version, submission status, and follow-up date. Creates Google Calendar reminders at day 5 and day 10.
Safe to automate
7
Send Run Digest to Gmail
After each pipeline run, emails a summary: jobs found, jobs skipped (with reason), jobs applied to, errors encountered, and forms that needed manual input. Keeps you in the loop without requiring active monitoring.
Safe to automate

Critical Files to Configure Before First Run
blocklist.md must include Meta (active team matching), any prior employers, and STEM OPT conflicting companies.   target_criteria.md must define your minimum match score, acceptable seniority levels, remote preference, and OPT sponsorship requirements.   last_run_timestamp prevents duplicate submissions across runs.   Do a dry run in logging-only mode first to verify output quality before enabling live submission.
Setup Checklist
1
Configure context files in Drive
Create CLAUDE.md, master_resume.md, target_criteria.md, and blocklist.md in Google Drive. These define who you are, what roles qualify, and what Claude must never touch.
2
Set up n8n on your Alienware
Deploy n8n locally on your Alienware with a cron trigger every 6 hours. Add HTTP nodes for LinkedIn Jobs API, Indeed RSS, Wellfound, and Apify actors for Greenhouse/Lever career pages.
3
Install and test Claude in Chrome
Install the Claude in Chrome extension on your Alienware. Manually test one Wellfound application and one LinkedIn Easy Apply before enabling automated submission to verify form-fill accuracy.
4
Enable MCP connectors
Connect Google Drive, Gmail, and Google Calendar via MCP in Cowork. These handle resume storage, digest emails, and follow-up calendar events on every successful run.
5
Initialize the applications tracker
Create applications_tracker.json in Drive with fields: company, role, date, score, resume_version, status, follow_up_date. Seed it with your existing applications so deduplication works from day one.
6
Dry run before going live
Run the pipeline in logging-only mode first. Claude scores, tailors, and preps everything but does not submit. Review one full batch via the Gmail digest, then flip to live submission mode once quality looks good.
